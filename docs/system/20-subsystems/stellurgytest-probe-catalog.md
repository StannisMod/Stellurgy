## Purpose
`/stellurgytest` is a **test-only** server command tree: a flat verb dispatcher that gives scenario tests in
`src/test/` deterministic, side-effect-controlled observability into (and manipulation of) server-side Stellurgy
state. It is not gameplay — it is a **contract surface**. Each verb reads or drives one subsystem and prints
a single-line JSON blob that `TestClient.execute(...)` captures via the reusable framework's "say marker"
protocol. Registered only when the JVM carries `-Dstellurgy.tests=true` (or `-Dforge.test.server=true`);
in normal play the command is never installed. `TestProbeCommandRegistration.java:34`

## Responsibility boundary
Owns: the `stellurgytest` verb dispatch (`getName`→`"stellurgytest"`, permission level 4), the JSON envelope helpers, the
per-command (so per-server) `RocketEventRecorder`/`FakePlayerTicker`/chunk-ticket test fixtures, and the in-world structure
builders (`fixture …`). Does NOT own: any gameplay NBT key, packet, registry name, or config flag — every verb
**reads or drives state owned by another subsystem** (rocket-entity, satellite, atmosphere, …). It writes no
persistent state of its own; the NBT keys it touches (§State) are asserted through the owning class, not owned.

## Shared pattern (read once, applies to every row)
1. **Flat two-level dispatch.** `execute` lower-cases `args[0]` and `switch`es to a `handle*` method
   (`TestProbeCommand.java:81`); each handler dispatches its own **sub-verb** off the *next* token via
   `"x".equalsIgnoreCase(args[0])` / `.equals(sub)` / `case "x":`. `tail(args)` drops the consumed token
   between levels. Unknown verb → `{"error":"unknown subcommand","sub":"…"}`; unknown sub-verb → a
   per-handler `{"error":"unknown … subcommand — try …"}` usage blob.
2. **JSON envelope (contract).** Output is one line via `send`→`sender.sendMessage(TextComponentString)`
   (`:9631`). Success is `{"ok":true, …}` **or** a bespoke field map built by `jsonMap` (`:9644`); failure is
   `{"error":"<msg>"[, context…]}`. Strings pass `escapeJson` (`\`,`"`,`\n`,`\r` only — not a full JSON escaper)
   (`:9683`). `jsonMap` serialises Number/Boolean raw, int[]/List as arrays, **a nested `Map` as a nested
   JSON object**, everything else as a quoted string (a nested map rendered as a quoted `HashMap` string
   would claim to be JSON while being readable only by regex). `[V]`
3. **Uncaught-exception envelope.** `execute` wraps the whole switch in `catch(RuntimeException)` →
   `{"error":"<SimpleName>: <message>"}` (`:226`) so a probe never crashes the server thread.
4. **Arg parsing.** `parseIntOr(s, default)` — dim ids default to `Integer.MIN_VALUE` (the "invalid/absent"
   sentinel, rejected downstream), coordinates default to `0`. Positional, space-separated; no flags.
5. **World / dimension resolution.** Handlers fetch `server.getWorld(dim)` and emit
   `{"error":"world not loaded","dim":n}` on null. Several verbs (`tp`, `event dim-side-effects`,
   `chunk forceload`) actively `keepDimensionLoaded`+`initDimension` to bring a dim up — a deliberate
   chunk/dim load inside a command, acceptable only because this is a test harness.
6. **Reflection for private state.** `reflectInt(obj,field)` (`:9621`) and ad-hoc `getDeclaredField` reach
   `EntityRocket.destinationDimId`, `TileDockingPort.myIdStr`, etc. (The planet handler's tick count and delayed-transition count are read through the public accessors of `ServerState.planetEvents`, not by reflection, since the former statics were removed.) These
   probes are **coupled to private field names** and silently degrade (`Integer.MIN_VALUE` / error blob) if a
   field is renamed — a refactor hazard, not a runtime bug.
7. **Round-trip probes.** The `*-roundtrip` verbs write a real object to a fresh `NBTTagCompound` / `ByteBuf`
   via the production `writeToNBT`/`writeDataToNetwork`, decode into a **peer** instance, and report the
   observed fields + which keys were written — a live oracle for the C1/C2 save-and-wire contracts.

**And its opposite is NOT a verb, because it does not need to be** `[V, 2026-08-22]`. There is no
`unload-ships`: the substrate's own loading controller queues an unload every tick for any ship with
no player inside its unload distance (`WorldShipLoadingController.determineLoadAndUnload`), and
`permanentlyLoaded` is the single override. So releasing the hold IS the unload, deterministically,
and waiting for one is not waiting on chance. One was written and then removed the same hour: with
the hold on, the ship reloads before the queued unload lands; with it off, the substrate has already
unloaded before a probe round-trip can ask. There is no window in which such a verb demonstrably does
anything, so there is no way to pin it — and an unpinnable probe is worse than none. If this comes up
again, the answer is `permaload false` plus a poll.

## Mechanics
- **MECH-ART-01 — Conditional install gate.** `registerIfTestMode` installs the command **iff**
  `Boolean.getBoolean("stellurgy.tests") || Boolean.getBoolean("forge.test.server")` (or
  `forge.test.client`); else no-op. Every server start builds a NEW command instance, so its fixtures

## State & persistence — asserted, not owned
This subsystem owns **no** NBT key. It drives/asserts keys owned elsewhere (C1); they must appear here for
coverage. Docking-port keys `myId`/`targetId` (`TileDockingPort`, driven by `set-ids`/round-trips `:13974`);
capsule keys `dstDimid`,`srcDimid`,`dstLoc`,`srcLoc`,`motionDir` (`EntityElevatorCapsule`, via
`entity capsule-*` `:10536`); satellite keys `satId`,`satelliteId`,`satelliteName`,`dimId`,`posList`
(`SatelliteRegistry`/changer sats, via `satellite …` `:2311`). Test fixture state (`rocketEvents`' counters,
`chunkTickets`, `fakePlayer`, the parked generator / weight engine / seal lists) is held by the command
INSTANCE — memory of one server, gone with it — and is not static (`TestProbeCommand.java:2710-2725,22660,23099-23124`).

## Config surface
`config get <flag>` / `config set <flag> <value>` reflectively read/write `StellurgyConfiguration` fields (C4), for
keys in `CONFIG_WHITELIST` only. The verb itself is gated by MECH-ART-01, so the whole probe surface is fully
disabled outside test mode; no gameplay config flag gates it. `:4867`

A whitelisted key is also how a test states a tuned threshold WITHOUT restating it: the life-support e2e reads
`lifeSupportMaxPartialO2` to assert that oxygen stops exactly there, so retuning the band moves the test's
expectation with it instead of turning the test red.

## Planet generation verbs

The `space` verb group as a whole is **not** enumerated above; these
rows cover only the planet-generation verbs. They exist because the questions they
answer are impossible to write down as literals: which cell holds an unrealized landable body depends
on the seed, and what that body IS depends on a derivation nobody has run yet.

| sub-verb | args | drives / observes |
|---|---|---|
| `gen-install` | `<density> <minSpacing> [seed]` | installs a `ClusteredGalaxyGenerator` (built over the server's own report-once latch, `serverDimensions().reports()`) on the SAVE's `UniverseRegistry` and binds a seed (default: the registry's world seed); the generator and seed it replaced are parked on the probe command until `gen-reset`. A world with no `<galaxyGen>` runs authored-anchors-only, so without this a procedural-generation test measures an empty universe. **Per-server, not JVM-global**: the generator is an instance field of that server's registry and the park is the command's, so a second server never sees it; a shared-server class still MUST pair it with `gen-reset` because the next CLASS on the same server would. `TestProbeCommand.java:6091-6115` |

## Test coverage
This file **is** the test-support layer; it is exercised transitively by `src/test/` scenario suites
(subsystem `test-suite-map`) rather than by unit tests of its own. Round-trip verbs (MECH-ART-04/05) act as
in-harness assertions of the C1/C2 contracts.

## Failure modes & edge cases
- Reflective coupling to private field names (`destinationDimId`, `myIdStr`,
  `targetIdStr`, `set-state` keys) — a rename in the owning class silently degrades the probe
  to `Integer.MIN_VALUE` / an `{"error":…}` blob instead of failing loudly. `:9621`,`:13924`
- `RocketEventRecorder` counters are never reset within a server (INV-ART-07); a test that
  reads absolute `event-counts` (rather than a delta) on a shared server can see counts leaked from a prior scenario
  (they do not leak across SERVERS). `TestProbeCommand.java:23124`
- `escapeJson` is not a complete JSON string escaper (no `\t`/`\b`/`\f`/`\u00xx`);
  a probe echoing arbitrary text (e.g. a mod block-id or exception message containing a tab/control char)
  emits invalid JSON that the harness parser may reject. `:9683`
- The `getUsage` string (`:65`) lists ~20 verbs but ~50 are registered (missing
  `assembler`, `satellite-builder`, `config`, `star`, `entity`, `player`, `mission`, `docking-port`, …) —
  stale help text; cosmetic, test-only.
